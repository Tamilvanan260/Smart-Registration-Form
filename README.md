# Smart Registration Form

A responsive and interactive registration form built using **HTML, CSS, and JavaScript** with real-time form validation and user-friendly error messages.

## 🚀 Project Overview

The Smart Registration Form allows users to enter their personal information and create an account through a clean and responsive interface.

It provides real-time input validation, password confirmation, character counting, and form submission feedback to improve the user experience.

## ✨ Features

- **Full Name Validation** – Checks whether the name is entered correctly.
- **Email Validation** – Validates the email address.
- **Phone Number Validation** – Checks the phone number format.
- **Date of Birth** – Allows users to select their date of birth.
- **Gender Selection** – Provides gender selection options.
- **Password Validation** – Checks password requirements.
- **Confirm Password** – Ensures both passwords match.
- **Bio Character Counter** – Displays the number of characters entered (maximum 200).
- **Terms & Conditions** – Requires users to accept the terms before submission.
- **Real-Time Validation** – Displays validation feedback while users enter information.
- **Success Message** – Displays a confirmation message after successful registration.
- **Submit Button Control** – Enables submission when the required conditions are satisfied.

## 🛠️ Technologies Used

- HTML5 – Structure of the registration form.
- CSS3 – Styling, layout, and responsive design.
- JavaScript – Form validation and interactive functionality.
